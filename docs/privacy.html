Pastiq Privacy Policy

Your clipboard is personal.
We designed Pastiq around that.

Effective date: September 28, 2026

Short version: Pastiq V1 is local-first. Clipboard history, snippets and settings are intended to remain on your device. Pastiq V1 does not operate a cloud clipboard, require an account, or transmit clipboard contents to a Pastiq server.

1. What Pastiq stores

Pastiq can store clipboard history, snippets, folders, settings and related metadata such as timestamps, content type, source domain or page title when that information is available to the extension. This information is stored locally using browser storage such as IndexedDB.

2. What Pastiq sends

Pastiq V1 does not send clipboard contents, snippets or local history to a Pastiq-operated cloud service. The V1 architecture does not require an account or remote clipboard database.

3. Sensitive information

Clipboard data can contain passwords, authentication tokens, financial information and other sensitive material. Pastiq is designed to avoid capturing or expanding snippets in identifiable sensitive input fields, including password, hidden, credit-card and security-code fields. Users can also configure domains where clipboard capture should not run.

Because browser pages and websites vary, no software can reliably identify every sensitive value. Users should avoid intentionally copying secrets into clipboard history when they do not want those values retained locally.

4. Page and browser actions

Pastiq can provide actions such as copying selected or visible page text, copying the current URL or title, saving page information, and performing supported browser actions. These features operate using information that is accessible to the extension in the current browser context.

Pastiq does not intentionally bypass DRM, paywalls, authentication controls, browser origin security, or other access-control mechanisms.

5. Website hosting

This website is hosted using GitHub Pages. GitHub states that visitors to GitHub Pages sites have their IP address logged and stored for security purposes. Pastiq does not add Google Analytics, advertising trackers or third-party clipboard telemetry to this website.

For details about GitHub's handling of website traffic, please refer to GitHub Pages documentation and GitHub's applicable privacy documentation.

6. Future synchronization

Cross-device synchronization is planned for a future version and is currently marked “Coming Soon.” V1 does not upload clipboard history to a synchronization service. If synchronization is introduced, this policy will be updated before that feature is enabled and the storage and security model will be described clearly.

7. Data deletion

You can clear Pastiq's local clipboard history and settings using the extension's controls. Removing the extension or clearing its browser storage can also remove locally stored extension data, subject to Chrome's storage behavior.

8. Changes to this policy

If Pastiq's data practices change, this policy will be updated to describe the change. The effective date at the top of this page will be updated accordingly.

9. Contact

For questions about Pastiq's privacy practices, open an issue in the Pastiq GitHub repository.

Pastiq is an independent open-source project. This page describes the Pastiq extension and this website; it does not replace GitHub's own privacy terms for GitHub-hosted services.
